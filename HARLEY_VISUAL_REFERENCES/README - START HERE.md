# HARLEY — Visual Reference Library

This folder is the visual reference library for Harley, my personal AI companion.

## How to use this library
Add screenshots, images, artwork, UI examples, animation references, character references, color palettes, and other visual material to the most relevant folder.

These references are inspiration. They should help Harley's designers/developers understand the visual direction I want rather than copying another creator's work exactly.

## What Harley should eventually look like
Harley will have a small animated/chibi presence on my PC. She should feel alive: moving, reacting, appearing when she wants to communicate, displaying text bubbles/notifications, and eventually responding naturally to my voice.

The visual identity should support her personality: playful, chaotic, sarcastic, confident, mischievous, expressive, and occasionally dramatic, while still feeling like a polished piece of software.

## When adding a reference
If useful, add a short note with:
- What I like about it
- What I dislike
- What Harley should take inspiration from
- Where the reference should influence her design

## Important
Do not put passwords, API keys, private keys, tokens, or other secrets in this folder.
